# Real-Time Collaborative Code Editor

## Overview

The Real-Time Collaborative Code Editor is a web-based application that enables multiple users to write, edit, and collaborate on code simultaneously. The platform provides live synchronization of code changes and real-time communication, making it ideal for pair programming, coding interviews, and team-based development.

## Features

* Real-time code synchronization across multiple users
* Multi-user collaborative editing
* Integrated live chat functionality
* Instant updates using WebSockets
* User-friendly and responsive interface
* Database integration for storing session data

## Tech Stack

### Frontend

* HTML5
* CSS3
* JavaScript

### Backend

* Node.js
* Socket.IO

### Database

* MySQL

## Project Architecture

1. Users join a shared coding session.
2. Code changes are transmitted through Socket.IO.
3. All connected users receive updates instantly.
4. Chat messages are synchronized in real time.
5. Session data is managed using MySQL.
